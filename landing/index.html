nedviga-cli// недвижимость и аналитика Москвы

PyPI: nedviga-cli v0.1.2 AGPL-3.0 Python 3.11+ MCP-ready GPG-signed artifacts

CLI и Python SDK для подбора и анализа жилой недвижимости Москвы. Рабочий цикл: поиск, карточка решения, сравнение, торг, проверка новостроек и застройщиков, инфраструктура, мониторинг изменений, отчёт. Для ИИ-агентов — MCP-сервер, роли, JSON-конверты и per-record аудит. Прогнозов цен нет: медианы и watch-дельты — факты с датой.

Быстрый цикл

# подготовка: wizard проверит окружение
pip install nedviga-cli
nedviga-cli wizard doctor

# профиль семьи, поиск, сравнение, карточка, мониторинг
nedviga-cli wizard init --profile family --out ./kit
nedviga-cli search --source cian --rooms 2 --price-max 20000000 \
  --geo-districts "ЮАО,ЮЗАО" --out cards.json
nedviga-cli compare --file cards.json --format telegram
nedviga-cli card cards.json --format all --out ./out
nedviga-cli watch add --file cards.json
nedviga-cli watch check --offline fresh.json

# досье дома, шум, источники
nedviga-cli dossier match --address "улица Эталонная, дом 4"
nedviga-cli noise sync && nedviga-cli noise --lat 55.72 --lon 37.61
nedviga-cli source

Источники

КлассЧто даёт
ЦИАН, Авито, ДомкликЖивые объявления. Браузерные адаптеры работают только через ваш egress NEDVIGA_EGRESS_PROXY; без него источник честно отключается (source_disabled).
Открытые данные МосквыДосье домов, ЖКХ, реестр новостроек, застройщики по ИНН (банки, суды), шум-мониторинг.
ЕГРННе используется. Модуль приёма и проверки выписки — от собственника.

Аналитика решения

Семейная карта объекта

Сводный профиль объекта под заданный семейный сценарий: составные части оценки разложены по измеримым критериям.

Сравнительная матрица

Единый формат сравнения по shortlist; выгрузки в text, telegram и другое.

Медианы торга

По комплексу. При малой выборке — честный insufficient_sample, не выдуманная цифра.

Антиприманочные флаги

Разметка объявлений с признаками приманки: заниженная цена, стоковые фото, несоответствие метража.

Risk-скоринг

Взвешенная оценка рисков объекта; юридические триаж-маркеры — 11 флагов для первичного просмотра юристом.

Цепочки альтернатив

Если объект снят — подмены из той же локации по скорингу соответствия профилю.

Цикл сделки

Пайплайн статусов shortlist → offer → …, watch цен, снятия и перевыставления, дайджесты, автоподбор по профилю. Артефакты — PDF/HTML-каталог, PPTX-презентации (deck), план показов, прозвон-листы, чек-листы передачи юристу.

# Python SDK
from nedviga.sources_avito import parse_livetext
from nedviga.deck import deck_from_cards
cards = parse_livetext(open("avito_text.txt").read())
deck_from_cards(cards, "подборка.pptx", title="ЮАО, двушки")

Контракт вывода

Один JSON-конверт в stdout: ok/status/reason/source/data/metadata. Логи — в stderr. Поведение при деградации источника определено кодами выхода.

КодЗначение
0Данные получены, контракт валиден.
1Критично для окружения: нет браузерного рантайма/кэша.
2Деградация источника: WAF, капча, rate-limit.
3Ошибка источника/парсера: изменение DOM, source_disabled, source_blocked.
4Невалидные аргументы CLI.

Безопасность

Fail-closed страж

Сетевой страж на egress-пути: сбой конфигурации отключает живые источники, а не работает «как получится».

Spotlighting

Внешний текст помечается <external_untrusted_data> — модель не путает чужие данные со своими инструкциями.

Роли и аудит

Per-record аудит действий; разграничение по ролям встроено в контур.

ПДн-минимизация

Контакты извлекаются только по явному флагу с указанной целью. Идемпотентный purge состояния.

Установка и конфигурация

# из PyPI
pip install nedviga-cli

# из репозитория
pip install git+https://github.com/lnfnt/nedviga-cli.git

# один раз: браузерный рантайм для live-адаптеров
XDG_CACHE_HOME="$HOME/.cache/nedviga-py" python3 -m camoufox fetch
ПеременнаяНазначение
NEDVIGA_EGRESS_PROXYHTTP-выход для браузерных адаптеров; без него живые источники = source_disabled.
NEDVIGA_MOS_TOKEN_FILEФайл ключа api.mos.ru (путь, не значение в env).
NEDVIGA_STATE_DIRКаталог состояния.
NEDVIGA_FEED_URLОпциональный сервер манифестов свежести адаптеров.

Ограничения: данные московские (для других городов адаптеров нет); прогноз транспорта — web-оценка и помечается как негарантийная.
